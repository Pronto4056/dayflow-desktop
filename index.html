Before you begin

Useful details.

Where is my information stored?+

Locally under %APPDATA%\DayFlow. The desktop shell uses this stable folder. Close DayFlow and back it up before updating; Windows update retention still requires testing.

Does DayFlow connect to my bank?+

No. All financial information is entered manually.

How do I install DayFlow?+

Download the Windows installer, open it, and follow the setup prompts. Because version 1.0.0 is unsigned, Windows SmartScreen may show an Unknown publisher warning.

Can I also use the web version?+

Yes. Open the actual browser review build, which stores its data in your browser. The example above remains an illustrative demo. Reviewed fixes are available in the browser build but are not included in the downloadable 1.0.0 Windows installer.
